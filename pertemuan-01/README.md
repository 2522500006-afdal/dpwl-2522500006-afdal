# pertemuan-01
1.Kesinambungan PWD-DPW-DPwl
jawaban:PWD(dasar),DPW(dikembangkan),DPWL(dilanjutkan),suatu perancangan yang berkembang dari membuat tampilan sebuah web ->membuat web yang dapat mengolah data->membangun aplikasi web yang lebih terstruktur/disusun secara rapi yang memiliki bagian yang jelas.
2.perbedaan PHP terstruktur dan MVC
jawaban:1.PHP lebih berstruktur sederhana
        2.MVC lebih tertata rapi/terstruktur cocok untuk sebuah aplikasi besar
3.Fungsi Model, View, dan Controller
jawaban:
        1.Model itu untuk bertugas mengelola data, termasuk mengambil, menyimpan, mengubah, dan menghapus data dari sebuah database.

        2.View berfungsi/bertugas menampilkan data kepada pengguna dalam bentuk halaman atau antarmuka suatu aplikasi.

        3.Controller untuk mengatur alur aplikasi, menerima permintaan dari pengguna, memprosesnya melalui Model, lalu menampilkan hasilnya melalui View.
4.Alur request–response MVC
jawaban:User mengirim request → Controller memproses → Model mengolah data → hasil dikirim ke View → View menampilkan hasil kepada user.
5.Pemetaan satu atau beberapa bagian/fitur aplikasi DPW ke Model, Controller, dan View disertai alasan
jawaban:
        1.Model: Mengelola data dan database.

        2.Controller: Mengatur proses dan alur fitur aplikasi.

        3.View: Menampilkan tampilan yang dilihat pengguna.

        Alasan: Agar setiap bagian memiliki tugas yang jelas dan kodenya lebih mudah dikelola.
6.kesimpulan P1
jawaban:
        Jadi kesimpulan dari P1 adalah Mempelajari banyak pembelajaran lanjutan seperti PHP terstruktur dan MVC sama-sama digunakan untuk membuat aplikasi,MVC yang membagi kode menjadi Model, View, dan Controller agar lebih terstruktur seperti User → Controller → Model → View → User. Pembagian membuat setiap bagian memiliki tugas yang jelas sehingga aplikasi lebih mudah dipahami dan dikelola.
